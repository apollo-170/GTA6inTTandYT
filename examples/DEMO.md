# Пример проверки без ключей

1. Запустить `npm run dev` для браузерного предпросмотра или `npm run dev:desktop`.
2. Убедиться, что в «Настройках» включено «Демонстрационный режим».
3. Перейти в «Стримеры», добавить `example_streamer`.
4. Нажать «Начать отслеживание».
5. Перейти в «Моменты», нажать «Тестовый всплеск».
6. Открыть карточку события и увидеть score/length.
7. В настоящем Windows-приложении можно прикрепить своё локальное видео через «Видеостудию» и выполнить FFmpeg-экспорт.

**Важно:** демо не скачивает и не публикует чужие видеоклипы.
